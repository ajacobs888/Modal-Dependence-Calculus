## Abstract
A longstanding thesis in metaphysics is that contingent entities depend for their existence on something that cannot fail to exist. This paper develops the Modal Dependence Calculus (MDC), a minimal extension of quantified S5 that formalizes this dependence using modal resources and a world-relative existence predicate E(x), where E(x) indicates that x is actualized at a world w. Dependence is defined via asymmetric modal entailment: D(x,y) holds if and only if x cannot be actualized unless y is, while y can be actualized without x.

Nine axioms (A0-A8) encode the structural constraints on dependence: irreflexivity, asymmetry, transitivity, the impossibility of infinite descent, and the linkage between invariance and necessity. From these, MDC establishes three central theorems:
1. Every contingent entity depends on something invariant across possible worlds.
2. Any invariant entity is necessary within the adopted modal framework.
3. There is exactly one such invariant necessary terminus within that framework, called the Core (c).

---

## Core Axioms Overview
* **A0:** Contingency
* **A1:** Irreflexivity (anti-self-dependence)
* **A2:** Asymmetry (strict directional order)
* **A3:** Transitivity 
* **A4:** Well-foundedness (No infinite descending D-chains)
* **A5:** Contingency preserves-E
* **A6:** Direct dependence on invariant
* **A7:** Invariance suffices for necessity
* **A8:** Modal-relational indiscernibility entails identity
