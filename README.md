## Abstract
A longstanding thesis in metaphysics is that contingent entities depend for their existence on something that cannot fail to exist. This paper develops the Modal Dependence Calculus (MDC), a minimal extension of quantified S5 that formalizes this dependence using only modal resources and a world-relative existence predicate $E(x)$, where $E(x)$ indicates that $x$ is actualized at a world $w$. Dependence is defined via asymmetric modal entailment: $D(x,y)$ holds if and only if $x$ cannot be actualized unless $y$ is, while $y$ can be actualized without $x$[span_3](start_span)[span_3](end_span).

Nine axioms (A0-A8) encode the structural constraints on dependence: irreflexivity, asymmetry, transitivity, the impossibility of infinite descent, and the linkage between invariance and necessity. From these, MDC establishes three central theorems:
1. Every contingent entity depends on something invariant across possible worlds[span_4](start_span)[span_4](end_span).
2. Any invariant entity is necessary within the adopted modal framework[span_5](start_span)[span_5](end_span).
3. There is exactly one such invariant necessary terminus within that framework, called the **Core ($c$)**[span_6](start_span)[span_6](end_span).

## Core Axioms Overview
* **A0:** Contingency[span_7](start_span)[span_7](end_span)
* **A1:** Irreflexivity ($\neg D(x,x)$)[span_8](start_span)[span_8](end_span)
* **A2:** Asymmetry ($D(x,y) \rightarrow \neg D(y,x)$)[span_9](start_span)[span_9](end_span)
* **A3:** Transitivity[span_10](start_span)[span_10](end_span)
* **A4:** Well-foundedness (No infinite descending D-chains)[span_11](start_span)[span_11](end_span)
* **A5:** Contingency preserves-$E$[span_12](start_span)[span_12](end_span)
* **A6:** Direct dependence on invariant ($C(x) \rightarrow \exists y(D(x,y) \wedge U(y))$)[span_13](start_span)[span_13](end_span)
* **A7:** Invariance suffices for necessity ($U(x) \rightarrow N(x)$)[span_14](start_span)[span_14](end_span)
* **A8:** Modal-relational indiscernibility entails identity[span_15](start_span)[span_15](end_span)
